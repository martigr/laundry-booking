Laundry Booking
Features Screenshots Get started GitHub

Book the shared washing machine in one click.

A small, self-hosted web app for apartment buildings. Residents see a week calendar with three slots per day and book a free one with a single click. Whoever is first gets the slot; if something doesn't fit, neighbours talk to each other.

Get started View on GitHub

Simple on purpose

No quotas, no app store, no accounts per person. One login per household, a German user interface, and it runs on a single small server.

One click to book

Click a free slot to book it, click your own booking to cancel it. "Ganzer Tag" books every free slot of a day at once.

Week and month view

The week calendar is the default; the month overview shows the bigger picture. Both work well on phones.

At a glance

A "now in the laundry room" card, the next free slot and your upcoming bookings, with adjacent slots shown as one block.

Mail reminders

Optional per user: a reminder before your booking, a note when a slot becomes free, and password reset. One-click unsubscribe.

Minimal admin area

Create and delete households, reset passwords, set how many weeks ahead people can book, cancel any booking.

Small and safe

Flask and SQLite, no JavaScript framework, no external CDNs. CSRF protection on every form and an unprivileged Docker container.

Get started

Run it with Docker Compose on any small server, behind an HTTPS reverse proxy. The first admin is created from the environment; everyone else is added in the app under Verwaltung.

Production (Docker Compose)

git clone https://github.com/martigr/laundry-booking
cd laundry-booking
cp .env.example .env   # SECRET_KEY, admin, BASE_URL, mail
docker compose up -d --build

Try it locally

python -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
flask --app laundry --debug seed-demo
flask --app laundry --debug run
# http://localhost:5000  alice / password123

Configuration, mail setup, volumes and the command line are described in the README; architecture and conventions in docs/DEVELOPMENT.md.
